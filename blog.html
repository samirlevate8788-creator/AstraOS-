27 SEPTEMBER 2026 · V0.1 ALPHA

The first AstraOS live image is ready

AstraOS 0.1 takes the first practical step: a Debian 13 live system that boots into an AstraOS-branded XFCE desktop. The image includes a browser, terminal, text editor, networking, disk utilities, developer essentials, a custom boot menu, wallpaper and a welcome app.

The boot catalog contains BIOS and UEFI entries. The locally built UEFI loader is unsigned, the image is live-only, and compatibility still needs testing across real PCs and virtual machines.
