Release notes and practical progress from the AstraOS project.

28 SEPTEMBER 2026 · 0.2.0-ALPHA SOURCE IN DEVELOPMENT

Ethical Security Lab and website hardening

The source tree now includes a defensive security tool set, an offline local-lab guide, AstraOS welcome-screen access to the guide, and updated boot and desktop branding. The website now has privacy and terms pages, optional analytics consent, a custom 404 page, per-page search and social metadata, and improved form behavior.

This is source work only. The downloadable ISO is still v0.1.1; the new configuration has not yet been built into a release ISO.

Open the Ethical Security Lab guide

27 SEPTEMBER 2026 · V0.1.1 BOOT HOTFIX

AstraOS boots in BIOS and UEFI virtual machines

AstraOS 0.1.1 fixes the BIOS Syslinux modules and UEFI boot image packaging for the Debian 13 live desktop. QEMU/KVM tests reached the branded XFCE desktop in both BIOS and UEFI modes, and the XFCE terminal opened successfully.

The image includes Firefox ESR, Mousepad, networking and disk tools, developer essentials, AstraOS wallpaper, boot menu and welcome app. It is still a live-only preview with no disk installer; the unsigned UEFI loader may require Secure Boot to be disabled. Testing on physical PCs remains open.
