27 SEPTEMBER 2026 · V0.1.1 BOOT HOTFIX

AstraOS boots in BIOS and UEFI virtual machines

AstraOS 0.1.1 fixes the BIOS Syslinux modules and UEFI boot image packaging for the Debian 13 live desktop. QEMU/KVM tests reached the branded XFCE desktop in both BIOS and UEFI modes, and the XFCE terminal opened successfully.

The image includes Firefox ESR, Mousepad, networking and disk tools, developer essentials, AstraOS wallpaper, boot menu and welcome app. It is still a live-only preview with no disk installer; the unsigned UEFI loader may require Secure Boot to be disabled. Testing on physical PCs remains open.
