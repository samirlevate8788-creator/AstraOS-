General Questions

Everything you need to know before getting started.

What is AstraOS?

AstraOS is a modern educational open-source operating system designed to help students learn operating system development through practical experience.

Is AstraOS free?

Yes. AstraOS is completely free and released under the MIT License.

Who created AstraOS?

AstraOS is an educational open-source initiative founded to encourage learning, collaboration, and innovation in operating system development.

Can beginners use AstraOS?

Absolutely! Beginners, students, and experienced developers are all welcome.

Installation Questions

Frequently asked questions related to installing and running AstraOS.

How do I install AstraOS?

Download the latest ISO, verify the SHA-256 checksum, create a virtual machine using QEMU or VirtualBox, attach the ISO, and boot the system.

Which virtual machines are supported?

AstraOS is designed primarily for QEMU and is also compatible with VirtualBox and VMware for testing.

Can I install AstraOS on real hardware?

At the current development stage, we recommend testing in a virtual machine. Native hardware support will improve in future releases.

Why does the ISO not boot?

Ensure virtualization is enabled, the ISO downloaded correctly, and the VM is configured with compatible settings.

Development Questions

Which programming languages are used?

AstraOS is primarily developed using C and x86 Assembly, with Make for the build system.

Which tools do I need?

Install GCC, NASM, Make, Git, and QEMU. VS Code is recommended as the editor.

Where is the source code available?

The complete source code is hosted on the official AstraOS GitHub repository.

Can I suggest new features?

Yes! Feature requests, discussions, and ideas are welcome through GitHub Issues and Discussions.

Common Installation Issues

ISO Error

Re-download the ISO and verify its integrity before booting.

Low Memory

Allocate at least 128 MB RAM. 512 MB or more is recommended.

CPU Issues

Use an x86-compatible virtual machine configuration.

Build Problems

Verify that GCC, NASM, Make, and Git are installed correctly.

Contribution Questions

Everything you need to know before contributing to AstraOS.

How can I contribute to AstraOS?

You can contribute by fixing bugs, developing new features, improving documentation, testing builds, or reviewing pull requests.

Do I need operating system development experience?

No. Beginners are welcome. We encourage learning through documentation, discussions, and small starter tasks.

Can I contribute only to documentation?

Absolutely. Documentation, tutorials, translations, and examples are valuable contributions.

Where can I find beginner-friendly tasks?

Check the GitHub repository for issues labeled good first issue or help wanted.

Security Questions

How do I report a security issue?

Please report security vulnerabilities privately to the project maintainers instead of creating a public issue.

Is AstraOS secure?

Security is an ongoing priority. New protections and improvements are added as the project evolves.

Will AstraOS receive security updates?

Yes. Important security fixes will be included in future releases whenever applicable.
