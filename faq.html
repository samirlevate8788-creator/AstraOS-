ASTRAOS 0.1 ALPHA

Frequently asked questions

Quick answers for trying the first AstraOS live image.

What is AstraOS 0.1?

A Debian 13-based amd64 live system with an AstraOS-branded XFCE desktop, browser, everyday system tools and developer essentials.

Does it install or change my PC?

No installer is included. It runs as a live session from USB. Writing the ISO to a USB drive erases that USB drive.

What PC does it target?

The image targets 64-bit amd64 PCs and includes BIOS and UEFI boot entries. Compatibility has not yet been tested across different physical PCs.

Why might UEFI block it?

The v0.1 UEFI loader is unsigned. Secure Boot may need to be disabled in firmware to start AstraOS.

Does v0.1 include a custom kernel or AstraFS?

No. It uses the Debian kernel and Linux desktop stack. AstraOS-specific utilities come first on the roadmap; custom kernel or filesystem work is future research.

Can I use a virtual machine?

The ISO is built as a hybrid image for BIOS and UEFI boot, but QEMU and VirtualBox runtime testing is still pending. Treat this as an early preview.

Where are the source and build instructions?

They are in the GitHub os/ folder and on the documentation page.
