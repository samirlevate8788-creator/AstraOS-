AstraOS 0.2.1-alpha Preview

BIOS + UEFI boot entries included · desktop startup unverified · amd64 / x86-64

LIVE DESKTOP · BIOS + UEFI

Try AstraOS from a USB drive

This Debian 13 live preview packages an AstraOS XFCE desktop, LibreOffice, Firefox ESR with uBlock Origin, defensive security tools, KeePassXC, firewall controls, AppArmor and a loopback-only practice lab. The BIOS boot menu appears in QEMU, but the desktop did not render during our check; desktop startup and physical-PC compatibility are unverified.

This is an early pre-release. Try it in a virtual machine first and keep important data backed up. It runs live, has no disk installer, and session changes disappear at shutdown. The UEFI loader is unsigned; Secure Boot may need to be disabled.

Boot from USB

1. Download and extract

Download the single ZIP file and extract it to get the complete ISO. Save the SHA-256 text file beside it and verify before writing the image.

2. Write the image

Use an image-writing utility and an 8 GB or larger USB drive. Writing erases the selected USB.

3. Start AstraOS

Choose the USB in your PC's boot menu. If UEFI blocks the unsigned loader, turn off Secure Boot in firmware.

What this build is

A Debian-based Linux live image that starts an AstraOS-branded XFCE desktop. It targets 64-bit amd64 PCs. This first preview has not yet been validated across different physical computers and does not install to the internal drive.
