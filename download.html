AstraOS 0.1 Alpha

First public live image · 27 September 2026 · amd64 / x86-64

LIVE DESKTOP · BIOS + UEFI

Try AstraOS from a USB drive

The ISO includes an XFCE desktop, Firefox ESR, terminal, Mousepad, networking and disk tools, developer essentials, AstraOS wallpaper, boot menu and welcome app.

This is an early preview. It runs as a live system and does not include an installer. The UEFI loader is unsigned; Secure Boot may need to be disabled.

Boot from USB

1. Download

Save the ISO and checksum. Verify the SHA-256 value before writing the image.

2. Write the image

Use an image-writing utility and an 8 GB or larger USB drive. Writing erases the selected USB.

3. Start AstraOS

Choose the USB in your PC's boot menu. If UEFI blocks the unsigned loader, turn off Secure Boot in firmware.

What this build is

A Debian-based Linux live image that starts an AstraOS-branded XFCE desktop. It targets 64-bit amd64 PCs. This first preview has not yet been validated across different physical computers and does not install to the internal drive.
