Quick Installation

  1. Download the AstraOS ISO image.
  2. Verify the SHA-256 checksum.
  3. Create a virtual machine in QEMU or VirtualBox.
  4. Attach the ISO image.
  5. Boot the virtual machine.
  6. Start exploring AstraOS.

Download FAQ

Is AstraOS free?

Yes. AstraOS is completely free and open-source under the MIT License.

Can I use AstraOS in VirtualBox?

Yes. AstraOS supports QEMU and VirtualBox for development and testing.

Can I contribute to AstraOS?

Absolutely! Visit the Contribute page to get started.

Will physical hardware be supported?

Yes. Future releases will gradually improve support for real hardware.

Troubleshooting

ISO Won't Boot

Verify the download, check the SHA-256 checksum, and recreate the virtual machine.

Insufficient Memory

Allocate at least 128 MB RAM (512 MB recommended).

Build Errors

Ensure GCC, NASM, Make, and QEMU are installed correctly.

Need Help?

Refer to the official documentation or contact the AstraOS team.
