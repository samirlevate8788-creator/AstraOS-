Getting Started

Follow these simple steps to begin contributing to AstraOS.

Step 1 — Fork the Repository

Fork the AstraOS repository to your personal GitHub account.

Fork Repository

Step 2 — Clone Your Fork


"https://github.com/samirlevate8788-creator/AstraOS-"

cd AstraOS

Step 3 — Add Upstream Repository


git remote add upstream
"https://github.com/samirlevate8788-creator/AstraOS-"

git remote -v

Branch Strategy


main

│

├── development

│

├── feature/kernel

├── feature/filesystem

├── feature/shell

├── feature/gui

└── hotfix

Always create a new feature branch before starting work.

Create a Feature Branch


git checkout -b feature/my-feature

Use meaningful branch names that clearly describe your work.

Coding Standards

Follow these guidelines to keep the AstraOS codebase clean and maintainable.

  • ✔ Write clean and readable code.
  • ✔ Use meaningful variable and function names.
  • ✔ Add comments for complex logic.
  • ✔ Keep functions small and modular.
  • ✔ Follow the existing project structure.
  • ✔ Test your code before submitting.

Commit Message Guidelines


feat: Add shell command support

fix: Resolve memory allocation bug

docs: Update installation guide

style: Improve website layout

refactor: Optimize bootloader code

test: Add kernel unit tests

Issue Reporting

Bug Report

Describe the issue clearly and include reproduction steps.

Feature Request

Suggest new ideas that can improve AstraOS.

Questions

Ask technical questions through GitHub Discussions or Issues.

Pull Request Workflow

  1. Fork the repository.
  2. Create a feature branch.
  3. Write and test your code.
  4. Commit your changes.
  5. Push your branch.
  6. Open a Pull Request.
  7. Address review comments.
  8. Merge after approval.

Code Review Process

Review

Core maintainers review every Pull Request.

Testing

Changes are verified before merging.

Merge

Approved contributions become part of AstraOS.
