About AstraOS

AstraOS is a modern open-source educational operating system developed from scratch to help students and developers understand kernel development, memory management, scheduling, file systems, networking, shell development, and operating system architecture through practical implementation.

Core Features

Explore the powerful components of AstraOS.

Kernel

Custom kernel built from scratch using C and x86-64 Assembly.

Memory Management

Efficient memory allocation and virtual memory support.

AstraFS

Fast, lightweight and educational custom file system.

Shell

Interactive command-line interface for managing the system.

Networking

Networking stack for future internet connectivity.

Security

Modern security concepts integrated into the OS architecture.

Development Roadmap

Our journey towards building a complete educational operating system.

Phase 1 - Planning

Research operating system architecture, define project goals, prepare documentation and organize the development team.

Phase 2 - Bootloader & Kernel

Build the bootloader, initialize the kernel, memory management and interrupt handling.

Phase 3 - Shell & File System

Develop Astra Shell, process management, AstraFS and storage drivers.

Phase 4 - Networking

Add networking stack, sockets, internet support and communication modules.

Phase 5 - GUI

Build a modern graphical desktop, application framework and package manager.
