SECURE DEFAULTS · NOT MAGIC

Reduce risk.
Keep control.

A layered baseline makes common attacks harder, but no operating system can promise that nobody will ever break in. Keep software updated and protect your accounts and files.

01

Inbound firewall
UFW defaults to blocking unsolicited incoming connections.

02

AppArmor
Linux application confinement is included and enabled in the boot configuration.

03

Website stays quiet
No analytics, cookie banner or startup overlay on the redesigned site.

START SMALL · LEARN DEEPLY

A lab flow that
keeps scope clear.

The toolkit gives you a place to begin, explains where a command is meant to run, and keeps the practice web target on the local machine.

01

Start the local target

Open AstraOS Security Toolkit and start the sample site. It listens only at 127.0.0.1:8765.

02

Choose a learning tool

Read the tool description and copy a loopback or owned-file example. The toolkit never runs a command for you.

03

Review what happened

Explain the output, stop the target, and write down what you learned. For other systems, get written authorization first.
