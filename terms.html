Terms and Conditions

Rules for the project website, source, and educational materials.

Project status

AstraOS is an educational Debian-based live desktop project. The currently published v0.1.1 image is a live preview; it has no disk installer and is not the new ethical security learning build. Source changes for a future 0.2.0-alpha build are in development and are not a released ISO.

Use of security tools

Only use security tools on systems you own or where you have clear, explicit permission. The guides are for learning and defensive administration. You are responsible for complying with applicable laws, contracts, and network rules. Do not use AstraOS material to access accounts, intercept other people's traffic, disrupt systems, or scan targets without authorization.

No warranty

The website, live image, source configuration, and guides are provided for educational use as available. The project makes no promise that they will work on every device, detect every issue, or be suitable for a production or safety-critical system. Back up important data before using system tools.

AstraOS packages Debian and other upstream software. Each package remains under its own license and terms. Review those licenses and upstream documentation before use. AstraOS is not affiliated with Debian, GitHub, Google, or the vendors of included tools.
