ASTRAOS · USER GUIDE

Start with AstraOS

Download, boot and use the Debian-based desktop, then explore its office tools and local security lab.

Get the current ISOFirst boot guide

Download and check the image

  1. Download the ISO and its SHA-256 checksum from the AstraOS download page.
  2. Check the checksum before writing the image. A mismatch means the file should not be used.
  3. Use an image-writing utility with an 8 GB or larger USB drive. Writing erases the selected drive.
  4. For a first look, try the ISO in a virtual machine before booting physical hardware.

AstraOS is a live preview with no disk installer. It runs from the USB image and does not replace Windows or another installed system.

Boot and sign in

  1. Restart and choose the USB drive from the PC's boot menu.
  2. Select the BIOS or UEFI option supported by the PC.
  3. The UEFI loader is unsigned. If firmware blocks it, Secure Boot may need to be disabled.
  4. The live desktop uses the username astra. Debian Live's public default password is live; change it for the current session with passwd before using administrator commands.

The live session resets when you shut down. Back up work to storage you trust, and do not store sensitive or irreplaceable data only in the live session.

Everyday apps and settings

Office

Use LibreOffice Writer, Calc and Impress for documents, spreadsheets and presentations.

Browser

Firefox ESR includes uBlock Origin and tracking protection. Review site permissions and notification requests.

System settings

Use XFCE Settings for display, sound, keyboard, network and desktop preferences.

Passwords

KeePassXC keeps a password vault encrypted. Protect the master password and secure any backup.

Firewall

UFW starts with inbound connections blocked. GUFW shows the current rules; understand a change before applying it.

File scans

ClamAV provides on-demand scans. Refresh signatures before use; it is not real-time protection.

Updates in a live session

Connect to the Internet, open Terminal, then run:

sudo apt update
sudo apt upgrade

Package updates and settings apply to the current live session and are lost at shutdown. A rebuilt ISO is needed for a durable updated image. ClamAV signature updates are user-started with sudo freshclam and use Internet data.

Common startup and desktop issues

USB will not boot

Check the image checksum, try the correct BIOS/UEFI entry, and check Secure Boot settings.

Display or sound

Open Applications → Settings. Try a lower display resolution or select the correct output device.

Network or firmware

Try wired networking and check whether the device needs extra firmware. Hardware coverage varies by PC.

Report a reproducible AstraOS issue through the AstraOS support page. Remove passwords, recovery keys, private keys, personal paths and private logs from reports. Never include sensitive personal data.

Use the security lab responsibly

The built-in practice site binds only to 127.0.0.1. Use guided tools only on your own computer, training VM, or a system covered by written permission. Read the offline lab guide before using a tool. No OS or scanner can promise zero bugs, attacks or false results.
