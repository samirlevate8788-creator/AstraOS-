Everything needed to try the v0.1 live image or rebuild it from the source configuration.

Boot the live system

  1. Download AstraOS-0.1-amd64.iso and its SHA-256 file.
  2. Verify the ISO checksum before writing it.
  3. Write the ISO to an 8 GB or larger USB drive with an image-writing utility. This erases the selected USB drive.
  4. Restart and choose the USB drive in the PC's firmware boot menu.
  5. If UEFI refuses to start the unsigned bootloader, disable Secure Boot in firmware and try again.

AstraOS starts as a live desktop and does not install onto the internal drive. This preview has not yet been tested across a range of PCs.

Build from source on Ubuntu or WSL

Use the repository's live-build configuration to generate the same amd64 image.

sudo apt update
sudo apt install --yes debian-archive-keyring live-build debootstrap \
  xorriso squashfs-tools grub-pc-bin grub-efi-amd64-bin mtools \
  isolinux rsync cpio git
git clone https://github.com/samirlevate8788-creator/AstraOS-.git
cd AstraOS-/os
sudo bash ./build.sh

The ISO and checksum are written to os/dist/. The build needs network access to Debian mirrors and several gigabytes of free space.

Build layout

Packages

os/config/package-lists/ selects the desktop, browser, tools and developer packages.

Branding

os/config/includes.chroot/ contains artwork, desktop settings and the welcome utility.

Boot image

os/build.sh creates the BIOS and UEFI hybrid ISO and EFI USB partition.

v0.1 scope

This is a Debian-based live distribution, not a custom kernel or installer. Its UEFI loader is unsigned, so Secure Boot is not supported by this preview. BIOS and UEFI boot entries are present in the image; PC-specific runtime compatibility still needs testing.
