Installation Guide

Follow these steps to set up AstraOS on your development machine.

Step 1 — Clone the Repository


git clone https://github.com/samirlevate8788-creator/AstraOS.git
cd AstraOS

Step 2 — Install Required Tools


✔ Git

✔ GCC Compiler

✔ NASM Assembler

✔ Make

✔ QEMU Emulator

Step 3 — Verify Installation


git --version

gcc --version

nasm -v

make --version

qemu-system-x86_64 --version

Build AstraOS

Compile the operating system from source.

Build Command


make clean

make

Generated Files

File Description
kernel.bin Compiled Kernel
boot.bin Bootloader
astraos.iso Bootable ISO Image

Run AstraOS

Launch AstraOS using QEMU Emulator.

Boot Command


qemu-system-x86_64 -cdrom astraos.iso
Tip: If virtualization is enabled, AstraOS will boot significantly faster.

Frequently Asked Questions

Common questions from AstraOS developers and contributors.

❓ Is AstraOS Open Source?

Yes. AstraOS is completely open-source and welcomes contributions from developers worldwide.

❓ Which programming languages are used?

AstraOS is primarily developed using C, Assembly (NASM), Makefile and Shell scripting.

❓ Can beginners contribute?

Absolutely! We encourage students and first-time contributors to participate in documentation, bug fixes, testing and feature development.

❓ Which platforms are supported?

Currently AstraOS targets the x86_64 architecture and is tested using QEMU.

Contribution Guidelines

Help us build AstraOS together.

Contribution Workflow

  1. Fork the AstraOS repository.
  2. Create a new feature branch.
  3. Write clean and documented code.
  4. Test your implementation.
  5. Commit your changes with meaningful messages.
  6. Push your branch to GitHub.
  7. Open a Pull Request for review.
Code Style: Follow consistent formatting, meaningful variable names and include comments where necessary.
