About AstraOS

Building the next generation educational operating system for students, developers and open-source contributors.

Our Story

The journey of AstraOS.

AstraOS started as a student-driven open-source initiative with a simple goal: make operating system development accessible to everyone. Instead of only studying theory, contributors build real kernel components, memory management, file systems, shells and networking modules together. The project encourages collaboration, learning and innovation while following real software engineering practices used in professional operating system development.

Vision & Mission

Driving the future of open-source operating system education.

Our Vision

To become one of the world's leading educational open-source operating system projects where students can learn real kernel development through practical experience and community collaboration.

Our Mission

Build a modern operating system from scratch while creating an open learning platform for developers, researchers and students interested in system programming.

System Architecture

How AstraOS is designed internally.

Bootloader

Responsible for loading the AstraOS kernel into memory and preparing the system before execution begins.

Kernel

The core of AstraOS handling processes, interrupts, scheduling and hardware communication.

Memory Manager

Efficient allocation, paging and memory protection for applications and kernel components.

AstraFS

Lightweight custom file system for storing and managing files efficiently.

Shell

Command-line interface allowing users to interact directly with the operating system.

Networking

Future implementation of internet protocols, sockets and communication services.
