A Linux base with an AstraOS identity

AstraOS is a Debian 13 live system shaped into a branded, approachable desktop for learners and developers.

Get the live imageSee the roadmap

What v0.1 includes

The first release focuses on a usable boot-to-desktop foundation.

Debian 13 base

A standard Debian kernel and package foundation keep Linux compatibility and updates familiar.

XFCE desktop

A light desktop environment starts directly from the live image.

AstraOS branding

Custom boot menu, splash, wallpaper, desktop defaults, logo and welcome utility.

Everyday tools

Firefox ESR, terminal, text editor, networking, disk utilities and developer essentials.

Project direction

We are starting with a bootable Linux distribution and AstraOS user experience. The v0.1 image does not contain a custom kernel, AstraFS, or a disk installer. AstraOS-specific settings, utilities and security/developer tools are planned next; independent kernel or filesystem work remains future research.
