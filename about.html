What v0.1 includes

The first release focuses on a usable boot-to-desktop foundation.

Debian 13 base

A standard Debian kernel and package foundation keep Linux compatibility and updates familiar.

XFCE desktop

A light desktop environment starts directly from the live image.

AstraOS branding

Custom boot menu, splash, wallpaper, desktop defaults, logo and welcome utility.

Everyday tools

Firefox ESR, terminal, text editor, networking, disk utilities and developer essentials.

AstraOS live desktop

The first release starts a Debian 13 XFCE session with AstraOS branding.

Project direction

The 0.2.1-alpha preview includes an authorized security-learning toolkit and offline lab guide, LibreOffice, Firefox ESR with uBlock Origin, AppArmor and an inbound-deny firewall baseline. The ISO is built, but its desktop did not render in our QEMU check; startup and physical hardware remain unverified. AstraOS uses the Debian kernel and has no disk installer.
