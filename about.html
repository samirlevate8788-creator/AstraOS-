A Linux base with an AstraOS identity

AstraOS is a Debian 13 live system shaped into a branded, approachable desktop for learners and developers.

Get the live imageSee the roadmap

What v0.1 includes

The first release focuses on a usable boot-to-desktop foundation.

Debian 13 base

A standard Debian kernel and package foundation keep Linux compatibility and updates familiar.

XFCE desktop

A light desktop environment starts directly from the live image.

AstraOS branding

Custom boot menu, splash, wallpaper, desktop defaults, logo and welcome utility.

Everyday tools

Firefox ESR, terminal, text editor, networking, disk utilities and developer essentials.

AstraOS live desktop

The first release starts a Debian 13 XFCE session with AstraOS branding.

Project direction

The 0.2.0-alpha source adds an authorized security-learning toolkit and offline lab guide, LibreOffice apps, Firefox ESR with uBlock Origin, AppArmor and an inbound-deny firewall baseline. These packages and settings are not in the currently published v0.1.1 ISO; the updated image still needs a Linux build and validation. AstraOS uses the Debian kernel and has no disk installer.
