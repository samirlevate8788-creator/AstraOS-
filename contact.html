Frequently Asked Questions

Find answers to common questions about AstraOS and contributing.

How can I contribute?

Fork the repository, create a new branch, make your changes, and submit a Pull Request on GitHub.

Do I need Operating System experience?

No. Beginners are welcome. If you're interested in learning, we'll help you get started.

Can I contribute to documentation only?

Yes! Documentation, testing, UI design, bug reporting, and code contributions are all valuable.

Is AstraOS open source?

Yes. AstraOS is a community-driven open-source educational operating system.
