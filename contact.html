ASTRAOS · SUPPORT

Help improve AstraOS

Send a clear, reproducible report about startup, desktop, office apps or the local security lab.

Email a bug reportTroubleshooting guide

What to include

Short steps and useful hardware details help reproduce a problem.

Expected and actual result

Describe what you were doing, what happened, and whether the issue repeats.

Device and boot mode

Include the AstraOS version, PC or virtual machine, and BIOS or UEFI mode.

Protect your data

Never include passwords, recovery keys, private keys, personal files or unredacted logs.

Privacy and storage

This static website does not submit or store a support form. The email button opens a draft in your mail app; review its contents before sending. AstraOS maintainers can use the local Docker feedback database for project tracking, but it is not connected to this public website.

For safe setup, read the AstraOS User Guide and Security Lab guide.
