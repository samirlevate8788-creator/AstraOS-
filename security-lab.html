Tools planned for the next image

These tools are in the 0.2.0-alpha source configuration. They are not included in the published v0.1.1 ISO yet.

Nmap

Inventory services on your own lab machine. Start a local test server, then inspect only loopback:

python3 -m http.server 8000
nmap -sV -p 8000 127.0.0.1

Wireshark + tcpdump

Observe packets you generate on your own computer. Choose the loopback interface and avoid capturing other people's traffic.

sudo tcpdump -i lo -nn

Open Wireshark, select the loopback interface, then visit http://127.0.0.1:8000.

Lynis

Run a local defensive configuration audit and use the report as a hardening checklist:

sudo lynis audit system --quick

Bandit

Find common security issues in Python code you own or are authorized to review:

bandit -r ./your-python-project

UFW

Review your machine's firewall state. Read the output before changing rules:

sudo ufw status verbose

Linux audit

Review local audit reports after auditd is configured and running:

sudo aureport --summary

Safe practice path

  1. Use a disposable virtual machine or a computer you own.
  2. Use loopback (127.0.0.1) for the network exercises on this page.
  3. Write down the expected result before running a tool, then explain what each output field means.
  4. For other systems, get written authorization that names the targets, time window, and allowed tests.
  5. Keep a backup and document any configuration change so you can undo it.

Do not: scan public or campus networks without permission, guess passwords, intercept other users, or run disruptive tests. A tool being installed does not mean a target is authorized.

Start with the AstraOS boot and build docs. The current published v0.1.1 release remains a basic live desktop; rebuild from the development source after reviewing packages if you want to test the future tool set.
