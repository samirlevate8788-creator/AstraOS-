YOUR FIRST EXERCISE

A safe target
already on your desktop.

The AstraOS Toolkit starts a small static site at 127.0.0.1:8765. It has no login, collection form, or remote services. The server binds to loopback only.

STEP / 01
▶

Start the sample site

Open AstraOS Security Toolkit from the welcome window or XFCE menu. Choose Start local lab, then Open lab site.

See local setup →
STEP / 02
⌁

Inspect this loopback host

Use only the built-in local practice target. These examples do not contact an internet host.

nmap -sV -p 8765 127.0.0.1
gobuster dir -u http://127.0.0.1:8765 -w /usr/share/astraos/lab-wordlist.txt
STEP / 03
■

Observe and stop

Study your own requests on the loopback interface. Stop the server from the Toolkit when the exercise ends.

sudo tcpdump -i lo -nn port 8765
Wireshark filter: tcp.port == 8765
