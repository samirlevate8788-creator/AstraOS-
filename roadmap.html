AstraOS Roadmap

Start with a working Linux base, then grow the AstraOS desktop and utilities step by step.

v0.1.1 Boot Hotfix · Built

The Debian live image is available as a GitHub release; BIOS and UEFI desktop startup are verified in QEMU/KVM.

Bootable base

Debian 13 live image with BIOS and UEFI boot entries.

AstraOS identity

Custom boot menu, splash, wallpaper, desktop defaults and welcome app.

Starter apps

XFCE, Firefox ESR, terminal, text editor, networking, disk tools and developer basics.

Next: physical hardware validation

Check the live image on representative PCs, including their graphics, Wi-Fi and storage devices. The unsigned UEFI loader may require Secure Boot to be disabled; hardware coverage is not yet established.

Planned after v0.1.1

Desktop settings

AstraOS settings panel, defaults and clearer first-run setup.

Software installer

A simple graphical path for finding and installing supported packages.

Developer & security tools

Add curated tools with clear documentation and safe defaults.

Custom OS research

Explore kernel, filesystem and desktop components as separate long-term work; they are not part of v0.1.
